# PEMROGRAMAN_BERORIENTASI_OBYEK
PEMROGRAMAN_BERORIENTASI_OBYEK (D3IF-48-01)
Repositori ini berisi seluruh materi, modul, kuis, dan tugas praktikum dari mata kuliah Pemrograman Berorientasi Obyek (PBO) untuk kelas D3IF-48-01.
Seluruh kode ditulis menggunakan bahasa Java dengan pendekatan berorientasi objek dan beberapa topik lanjutan seperti GUI dan Database Connection.

⚙️ Teknologi yang Digunakan
Bahasa: Java (JDK 17+)
Database: MySQL / SQLite
IDE: DBeaver, IntelliJ IDEA, NetBeans, atau VS Code
Tools Tambahan: JDBC, Java Swing
